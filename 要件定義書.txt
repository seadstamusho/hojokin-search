【0. 参照モデルの分析】
------------------------------------------------------------------
参照サイト：https://kabutan-proxy.yahabaera007.workers.dev/#
（ライオン兄さん監修 個別株AIツール）

構成の特徴：
・Cloudflare Workers で動く単一ページWebアプリ（HTML/CSS/JS）
・バックエンド = Cloudflare Workers（スクリーニング処理）
・データはワーカー内でCSV形式として返却
・AIなし・純粋なスクリプトフィルタリング
・パスワードによるコンテンツ保護（localStorage管理）
・運用コストゼロ（Cloudflare無料プラン：10万req/日）

補助金ツールへの転用イメージ：
・「業種選択」→「申請者プロフィール入力」
・「株のスクリーニング条件」→「補助金の受給条件との照合」
・「銘柄リスト」→「マッチした補助金一覧」
・「株探で見る」→「補助金公式サイトを見る」


================================================================
【1. システム概要】
================================================================

ツール名（仮）：補助金かんたん検索ツール

目的：
　申請者の属性・事業内容をフォームで入力するだけで、
　条件が合致する補助金・助成金を自動リストアップする。

対象補助金カバー範囲（3階層）：
　第1層（国）：jGrants掲載補助金（農業・中小企業・IT等）
　第2層（県）：山形県の農業補助金（逆引き事典ベース）
　第3層（町）：遊佐町の産業・農業支援制度

特徴：
　・AIなし（スクリプトによるキーワードマッチング＋条件照合）
　・運用コスト：ゼロ（Cloudflare無料プラン内）
　・補助金データ：ワーカー内JSONとして静的管理（手動更新）
　・パスワード保護機能：掲載コンテンツを制限可能（任意）


================================================================
【2. 技術スタック（Cloudflareで完結）】
================================================================

■ ホスティング
　Cloudflare Workers（無料：10万req/日、1MBスクリプトサイズ）

■ フロントエンド
　HTML / CSS / Vanilla JavaScript（単一ファイル埋め込み）

■ データ管理
　補助金データ = ワーカー内のJSONオブジェクト（静的定義）
　　→ 更新時はworkerスクリプトを手動で編集してデプロイ
　　→ 将来的にCloudflare KV（無料枠あり）への移行も可能

■ バックエンド処理
　フィルタリングロジック：
　　申請者の入力条件 ×× 補助金の受給条件 → スコアリング → 降順ソート
　レスポンス形式：JSON（フロントエンドで表示）

■ デプロイ
　wrangler CLI または Cloudflareダッシュボードから手動デプロイ

■ ドメイン
　*.workers.dev のサブドメイン（無料）
　または独自ドメイン設定（Cloudflare DNS管理ならゼロコスト）

【3. フェーズ1：ユーザー入力項目一覧】
================================================================

入力フォームは「ステップ形式」または「一画面まとめ」で表示。
絞り込みに使うキー項目のみ収集（5〜8項目以内が理想）。

------------------------------------------------------------------
【必須入力項目】
------------------------------------------------------------------

(A) 事業形態
　選択肢（ラジオボタン or セレクト）：
　　・個人事業主
　　・法人（株式・合同・有限会社等）
　　・農業法人・農業生産法人
　　・NPO・一般社団法人
　　・任意団体・グループ
　　・これから創業予定

(B) 業種（メインカテゴリ）
　選択肢：
　　・農業・林業・水産業（自然栽培・有機農業を含む）
　　・製造業
　　・建設業
　　・小売業・飲食業
　　・ITサービス・情報通信
　　・福祉・医療・介護
　　・観光・宿泊・エンタメ
　　・その他サービス業

(C) 所在地（都道府県 or 詳細）
　選択肢：
　　・山形県 遊佐町
　　・山形県（遊佐町以外）
　　・山形県以外の東北地方
　　・東北以外の全国

(D) 従業員数（常時雇用）
　選択肢：
　　・0人（個人・一人経営）
　　・1〜5人
　　・6〜20人
　　・21〜50人
　　・51〜300人
　　・301人以上

(E) 資本金
　選択肢：
　　・該当なし（個人事業主）
　　・300万円未満
　　・300万〜1,000万円
　　・1,000万〜5,000万円
　　・5,000万円超

(F) 創業・設立からの年数
　選択肢：
　　・創業前（これからスタート）
　　・1年未満
　　・1〜3年
　　・3〜5年
　　・5年超

(G) 今回の補助金で実現したいこと（複数選択OK）
　チェックボックス：
　　□ 農機・設備・機械の購入・導入
　　□ ITシステム・ソフトウェア導入（デジタル化）
　　□ 販路拡大・EC・海外展開
　　□ 新商品・新サービスの開発
　　□ 省エネ・環境対応（太陽光等含む）
　　□ 施設・建物の建設・改修
　　□ 雇用・人材育成・研修
　　□ 有機・自然栽培への転換
　　□ 事業再構築・業態変換
　　□ 創業・スタートアップ支援

------------------------------------------------------------------
【任意入力項目（精度向上のための追加質問）】
------------------------------------------------------------------

(H) 直近の年間売上高（任意）
　選択肢：
　　・100万円未満
　　・100〜500万円
　　・500万〜1,000万円
　　・1,000万〜3,000万円
　　・3,000万〜1億円
　　・1億円超
　　・未回答

(I) 特記事項（任意チェック）

【4. フェーズ2：マッチングロジック設計】
================================================================

------------------------------------------------------------------
【4-1. 補助金データ構造（JSONスキーマ）】
------------------------------------------------------------------

各補助金データは以下のフィールドを持つ：

{
  id: "001",
  name: "補助金名（例：ものづくり補助金）",
  category: "設備投資",               // 用途カテゴリ
  area: ["全国"],                      // 対象地域（"全国" / "山形県" / "遊佐町" 等）
  target_type: ["法人", "個人事業主"], // 対象事業形態
  industry: ["農業", "製造業"],        // 対象業種（"全業種"も可）
  max_employees: 300,                  // 対象従業員数（上限）
  max_capital: 5000,                   // 対象資本金（万円・上限）
  founding_year_min: 0,               // 設立経過年数（最低）
  founding_year_max: 99,              // 設立経過年数（最大）
  purpose: ["設備導入", "IT導入"],     // マッチングに使う用途タグ
  amount_max: "1000万円",              // 最大補助額
  rate: "2/3",                         // 補助率
  deadline: "2026-07-31",             // 申請期限
  status: "受付中",                    // 現在のステータス
  url: "https://example.go.jp/...",   // 公式URL
  note: "認定支援機関の関与が必要"     // 備考
}

------------------------------------------------------------------
【4-2. マッチングスコアリング方式】
------------------------------------------------------------------

各補助金に対して、ユーザー入力とのマッチ度を0〜100点でスコアリング。

スコア計算ルール（例）：
　・事業形態が一致：+20点
　・業種が一致：+25点
　・所在地が一致：+20点（全国対象なら+10点）
　・従業員数が条件内：+15点
　・用途タグが1個一致するごとに：+10点（最大+30点）
　・申請期限が今日より後（受付中）：+15点ボーナス
　・資本金・創業年数などの条件外：-50点（強制除外）

スコア0点以下は表示しない。
スコア上位N件（例：20件）を降順で表示。

------------------------------------------------------------------
【4-3. 表示フィルター】
------------------------------------------------------------------

結果一覧の上に追加フィルターを設置：

　・エリア絞り込み：全国 / 山形県 / 遊佐町
　・ステータス：受付中のみ / すべて
　・用途カテゴリ：全て / 設備投資 / IT / 農業 / 販路 等
　・補助額：100万円以上 / 500万円以上

【5. 表示形式（検索結果リスト）】
================================================================

参照サイト（株ツール）と同じ「テーブル形式」で表示。

------------------------------------------------------------------
テーブルカラム構成：
------------------------------------------------------------------

[補助金名（リンク）] [カテゴリ] [エリア] [補助率] [上限額] [期限] [ステータス] [公式を見る]

補助金名：クリックで詳細モーダル or 公式サイトへ遷移
ステータス：「受付中」＝緑バッジ / 「終了」＝グレー / 「近日開始」＝オレンジ

------------------------------------------------------------------
追加表示要素：
------------------------------------------------------------------

・マッチ度バー（スコア可視化）※オプション
・「〇件ヒット / 〇件中」の件数表示
・「条件を変更する」戻るボタン
・各行に「詳細を見る」で公式サイト外部遷移
