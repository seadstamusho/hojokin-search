【A. 補助金申請サポート機能】
================================================================

-----------------------------------
A-1. 機能の全体像（3段階で考える）
-----------------------------------

段階1：申請ステップガイド（AIなし・コストゼロ）
段階2：申請書類の自動生成（AI活用）
段階3：提出様式への自動当てはめ（AI活用・高度）

まずは段階1から始め、段階2→3へ順次昇格する。

-----------------------------------
A-2. 段階1：申請ステップガイド（AIなし）
-----------------------------------

【機能概要】
補助金の一覧から1件を選ぶと、以下の情報が展開表示される。

表示内容：
  1. この補助金を申請するためのステップ（番号付き手順）
  2. 必要書類のチェックリスト
  3. 申請窓口・担当機関の連絡先
  4. 注意点・よくある落とし穴
  5. 公式サイトへのリンク

実装方法：
  補助金データのJSONに「申請ガイド」フィールドを追加する。
  例：
  {
    id: "biz001",
    name: "ものづくり補助金",
    ...
    guide: {
      steps: [
        "認定経営革新等支援機関（認定支援機関）に相談する",
        "GビズIDプライムを取得する（2〜3週間かかるため早めに）",
        "事業計画書を作成する（10〜15枚程度）",
        "電子申請システムから申請する",
        "採択発表を待つ（公募締切から2〜3ヶ月後）",
        "採択後に補助事業を実施する",
        "実績報告書を提出する"
      ],
      required_docs: [
        "GビズIDプライム（必須）",
        "直近2期分の確定申告書・決算書",
        "事業計画書（所定の様式）",
        "賃金台帳のコピー"
      ],
      agency: "中小企業庁 / 全国中小企業団体中央会",
      caution: "認定支援機関の関与が必須。電子申請のみで紙申請不可。",
      url: "https://portal.monodukuri-hojo.jp/"
    }
  }

コスト：ゼロ（静的データ追加のみ）
難易度：低（現在のworker.jsを拡張するだけ）

-----------------------------------
A-3. 段階2：AI申請書類自動生成
-----------------------------------

【機能概要】
会社情報（フェーズ2-B で保存済みのデータ）＋ 選択した補助金の情報
→ AIが申請書の「事業計画書ドラフト」を自動生成する。

ユーザーの操作フロー：
  1. 補助金一覧から「この補助金に申請する」をクリック
  2. 会社情報が自動で読み込まれる（保存済みのもの）
  3. 追加質問（事業の特徴・課題・目的）を入力
  4. 「AIで書類を生成する」ボタンをクリック
  5. 事業計画書のドラフトが画面に表示される
  6. ダウンロード（Wordまたはテキスト形式）

AIに送るプロンプトの構成（例）：
  「以下の会社情報と事業内容をもとに、
   ものづくり補助金の事業計画書のドラフトを作成してください。

   会社名：○○○
   業種：農業
   従業員数：3名
   事業内容：自然栽培米の生産・販売
   申請する目的：農業機械（田植え機）の導入で作業効率を改善したい

   様式に沿った形で、各項目を具体的に書いてください。」

【使用するAI】
推奨：Claude API（claude-haiku-4-5）
理由：
  - 日本語の文書生成が高品質
  - Haiku は低コスト（1,000文字の生成で約0.5〜1円）
  - 事業計画書1件の生成コスト目安：約2〜5円

代替案：Cloudflare Workers AI（Llama等）
  - コストほぼゼロ（無料枠内なら）
  - ただし日本語品質がClaude/GPTより劣る

コスト試算（Claude Haiku使用の場合）：
  月100件の生成 → 約200〜500円/月
  月1,000件の生成 → 約2,000〜5,000円/月

【実装方針】
  - Claude APIキーをCloudflare Workersの環境変数に設定
  - /api/generate エンドポイントを追加
  - フロントエンドから会社情報＋補助金情報をPOSTして結果を返す

-----------------------------------
A-4. 段階3：提出様式への自動当てはめ（将来）
-----------------------------------

【機能概要】
各補助金の「公式様式（Excel/Word）」に、生成した内容を
自動で埋め込んだファイルを出力する。

実装の難しさ：
  - 様式はExcel/Wordが多く、自動化には専用ライブラリが必要
  - 補助金ごとに様式が全く異なる
  - 様式は毎年変更される可能性がある

現実的なアプローチ：
  まずは「テキスト形式のドラフト」をコピーして様式に貼る形で運用し、
  需要が高まったら自動埋め込みを実装する。

実装時期の目安：段階2が安定稼働してから着手。

【B. 会社情報保存機能】
================================================================

-----------------------------------
B-1. 必要な技術要素
-----------------------------------

Googleログインを実装するには、以下が必要：

  (1) 認証（Googleログイン）
  (2) データベース（会社情報の保存先）
  (3) セッション管理（ログイン状態の維持）

現在のCloudflare Workers単体ではこれらを全て賄うのが複雑なため、
追加インフラの選択が必要になる。

-----------------------------------
B-2. 技術スタック選択肢（3案）
-----------------------------------

【案A：Firebase（推奨）】
  認証：Firebase Authentication（Googleログイン）
  DB：Firestore（JSONベースのクラウドDB）
  ホスト：現状のCloudflare Workersのまま

  メリット：
    - Googleログインが最も簡単に実装できる
    - Firestore無料枠が十分（1GB/50,000読み取り/日）
    - フロントエンドのJSにSDKを追加するだけで動く
    - ダッシュボードが見やすく、データ管理が楽

  デメリット：
    - Googleのサービス（GCPに依存）
    - 大量アクセス時は課金発生（当面は無料枠内で十分）

  コスト：無料（無料枠内の利用ならゼロ）
  難易度：中

【案B：Cloudflare完結（D1 + Workers）】
  認証：Google OAuthを自前実装
  DB：Cloudflare D1（SQLiteベース）
  ホスト：Cloudflare Workers（現状と同じ）

  メリット：
    - 完全にCloudflare内で完結
    - D1は無料枠あり（5GBまで無料）

  デメリット：
    - Google OAuthの自前実装は複雑（トークン管理等）
    - 実装コストが高い

  コスト：無料
  難易度：高

【案C：Supabase】
  認証：Supabase Auth（Googleログイン対応）
  DB：Supabase（PostgreSQL）
  ホスト：現状のCloudflare Workersのまま

  メリット：
    - Googleログインが簡単
    - PostgreSQLなので複雑なクエリが書ける

  デメリット：
    - 別サービスへの依存が増える
    - 無料枠に制限あり（500MB・月2GBアウトバウンド）

  コスト：無料（無料枠内）
  難易度：中

→ 推奨は【案A：Firebase】
  Googleログイン実装の容易さとFirestoreの使いやすさで最もバランスが良い。

-----------------------------------
B-3. 拡充する入力項目一覧
-----------------------------------

現在の入力項目（毎回手動）：
  事業形態 / 業種 / 従業員数 / 所在地 / 用途

追加する入力項目（保存してプロフィール化）：

【基本情報】
  - 屋号・会社名
  - 代表者名
  - 郵便番号・住所（都道府県・市区町村・番地）
  - 電話番号
  - メールアドレス
  - Webサイト（任意）

【事業情報】
  - 事業形態（個人事業主 / 法人 / 農業法人 等）
  - 業種（大分類 + 詳細分類）
  - 具体的な事業内容（テキスト自由入力・200字以内）
  - 主要な商品・サービス名
  - 販売チャネル（直売 / EC / 卸 / 複合 等）
  - 農業の場合：栽培品目・農地面積（ha）・農業スタイル

【財務情報（任意）】
  - 従業員数
  - 資本金
  - 直近の年間売上高
  - 創業・設立年

【申請実績（任意）】
  - 過去に受給した補助金名（自由入力）
  - 現在申請中の補助金（自由入力）

-----------------------------------
B-4. データの保存・利用の流れ
-----------------------------------

初回利用：
  1. Googleログインボタンをクリック
  2. Google認証画面でアカウントを選択
  3. ログイン後、プロフィール入力フォームが表示される
  4. 入力して「保存」→ Firestoreに保存
  5. 以降の検索に自動反映

2回目以降：
  1. Googleログインで自動認識
  2. 保存済みの会社情報が自動でフォームにセット
  3. 変更があれば「プロフィール編集」から更新

プロフィールページ（新設）：
  - 会社情報の確認・編集
  - 過去の検索履歴
  - 気になる補助金のブックマーク（将来機能）
